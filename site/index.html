让普通照片，

Luma 是一款 Windows 原生照片查看器。原生 HDR 照片直接点亮；普通照片，甚至实况照片，也能借助 NVIDIA RTX Video HDR 增强光影。

· Windows 11 x64 · RTX HDR 与 VSR 需要兼容的 NVIDIA RTX 显卡

如果你有一块好 HDR 屏幕，别只用它看电影。 也用它，重新看看自己的照片。

亮点

原生 HDR，直接点亮。

带 HDR 信息的照片自动以 HDR 显示，不需要 RTX。图库角标，一眼看出照片的特性。

  • Ultra HDR JPEG
  • iPhone HEIC
  • JPEG XR

普通照片，也能 HDR。

借助官方 NVIDIA RTX Video HDR，为普通照片增强光影。

  • RTX HDR在顶部“显示增强”中开启
  • HDR 风格柔和、自然、鲜明，默认自然
  • VSR 超分辨率独立开关，默认关闭
  • 实况照片动态部分也能用 RTX HDR 预览
  • 按住 空格对比原图或可用的 SDR 底图

支持范围

支持什么，一目了然。

普通图片
JPEG、PNG、BMP、GIF、TIFF、ICO
原生 HDR
iPhone HEIC（Apple / ISO 增益图、PQ）；Android Ultra HDR / ISO / Apple 增益图 JPEG；线性 scRGB JPEG XR（JXR、WDP、HDP）。无需 RTX。
RTX HDR 与 VSR
官方 NVIDIA RTX Video HDR 增强普通 SDR 照片的光影；RTX VSR 是独立的 AI 超分开关，默认关闭。需要兼容的 RTX 显卡、驱动，以及开启 HDR 的屏幕。RTX HDR 是 AI 增强，不能恢复拍摄时没有记录的信息，也不保证每个区域都更亮。
实况 / 动态照片
已验证的 iPhone HEIC＋MOV，以及 Google、Pixel、三星、小米动态照片。动态部分可选 RTX HDR 预览，播放期间暂停 VSR。请保留 iPhone 配套的 MOV，Android 请导出完整原片；聊天软件转发后可能只剩静态图。
暂未支持
AVIF HDR、JPEG XL、OpenEXR、RAW、GIF 动画、原生 HDR 动态视频、.livp。HLG HEIC 尚未完成验证。
系统要求
Windows 11 x64。安装包内含 .NET、WinUI 与 NVIDIA 运行库；HEIC 需要 Windows 的 HEIF 图像扩展与 HEVC 视频扩展。

HDR 格式说明

开始体验

三步，用好你的 HDR 屏幕。

  1. 1

    开启系统 HDR

    在 Windows“设置 → 系统 → 显示”中选中屏幕，打开“使用 HDR”。

  2. 2

    检查屏幕校准

    用微软的 Windows HDR Calibration 按测试图案校准并保存配置。

  3. 3

    打开自己的照片

    原生 HDR 照片自动识别。普通照片，在顶部“显示增强”里开启 RTX HDR。
