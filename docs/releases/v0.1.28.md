# Luma 0.1.28

修复照片全屏预览时，屏幕顶部出现细白边的问题。

进入全屏时关闭 WinUI 自定义标题栏的保留区域，让画面覆盖整个屏幕；退出全屏恢复标题栏、原窗口大小、位置和最大化状态。F、F11 和工具栏按钮的操作方式保持不变。

已在 Windows 11、3840×2160 / 150% 缩放下完成 12 次全屏进出检查，覆盖深浅主题、普通和最大化窗口，以及切换焦点和详情面板开合。其他屏幕与缩放组合仍需继续覆盖。

## 下载与升级

- 安装包：`Luma-0.1.28-windows-x64-rtx-setup.exe`。
- 便携版：`Luma-0.1.28-windows-x64-rtx-portable.zip`，完整解压后运行 `Luma.App.exe`。
- 已安装旧版：退出 Luma 后直接运行新版安装器，图库、收藏和设置保留。

保留 0.1.27 的原生 HDR、RTX HDR / VSR 和实况照片能力。本次修复不改变照片解码或 HDR 映射；HDR 需要相应屏幕及 Windows HDR，RTX 增强另需兼容的 NVIDIA RTX 显卡与驱动，HEIC / 部分 HEVC 实况需要 Windows HEIF / HEVC 扩展。

GitHub 安装包未签名；本次发布不涉及微软商店提交。
