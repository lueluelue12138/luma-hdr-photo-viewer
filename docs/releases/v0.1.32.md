# Luma 0.1.32

找照片、整理相册更顺手，也修复了“照片已经显示，却提示无法打开”的问题。

## 这次更新

- **按照片类型筛选**：在相册、全部照片、收藏和最近打开中筛选 HDR、实况或普通静态照片，支持多选，也会记住你的选择。HDR 实况照片不会重复出现。
- **置顶与相册排序**：常看的相册可以置顶；相册首页支持按名称、添加顺序或照片数量排序，选择会保留。
- **照片预览更稳妥**：图库保存浏览记录、读取或保存收藏失败时，不再用“无法打开照片”遮住已经显示的画面。提示可以关闭，照片仍能继续查看和切换；真正缺失或无法解码的文件仍会明确报错。

照片类型在后台识别，最近识别过的结果会在本次运行中复用。首次筛选很大的相册仍可能需要等待；照片始终保留在原文件夹。

## 下载与升级

- 安装版：`Luma-0.1.32-windows-x64-rtx-setup.exe`。
- 便携版：`Luma-0.1.32-windows-x64-rtx-portable.zip`，完整解压后运行 `Luma.App.exe`。
- 已安装旧版：退出 Luma 后直接运行新版安装器，保留图库、收藏、最近记录和设置。

完整包保留原生 HDR、RTX HDR / VSR 和实况照片功能，不需要安装开发 SDK 或 .NET。HDR 显示需要开启 Windows HDR；RTX 增强另需兼容的 NVIDIA RTX 显卡与驱动；HEIC / 部分 HEVC 实况仍可能需要 Windows HEIF / HEVC 扩展。

本次修复不会自动清空或重建已有图库。如果提示图库数据需要检查，原照片仍保留在原处，建议反馈日志并保全数据库后再修复。

GitHub 安装包未签名。本次发布不包含微软商店提交。
