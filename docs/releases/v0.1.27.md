# Luma 0.1.27

**让回忆动起来，也让普通的片刻用上 HDR。**

这次更新加入实况 / Motion Photo 播放：照片里快门前后的动作和声音，可以直接在 Luma 里回放。动态部分为 SDR 时，还能选择 RTX HDR。

## 这次更新

- **实况照片预览。** 支持完整 iPhone HEIC＋MOV，以及已验证的 Google、Pixel、三星和小米动态 JPEG / HEIC。点击顶部同心圆图标或按 **L** 播放 / 停止，Esc 停止；首次默认静音，之后记住你的原声选择。
- **看出照片的特性。** 图库卡片增加适配深浅主题的 HDR / 实况磨砂角标；信息面板补充实况封装、视频大小，以及播放后可读的时长、尺寸和音轨信息。
- **操作更稳定。** 实况按钮在准备 / 播放 / 停止时保持同样大小；播放中图标呼吸并旋转。详情面板只有真正遮挡缩略图栏时才避让，宽窗口无碰撞时保持原位。
- **一键完整显示，也能铺满画面。** 缩放下拉框增加“填满窗口”，按比例铺满并裁去超出部分；旁边的适应按钮恢复完整画面，键盘 **1** 仍是 100% 像素视图。
- **减少播放时对窗口的占用。** 媒体打开、播放器创建和关闭在后台完成，与画面准备并行；实况不在导入或悬停时自动播放。
- **更新应用内帮助。** 设置里说明实况操作、原片保留方式、HDR / 视频边界和缩放档位。

## 下载与升级

- 日常安装：`Luma-0.1.27-windows-x64-rtx-setup.exe`。
- 便携使用：`Luma-0.1.27-windows-x64-rtx-portable.zip`，完整解压后运行 `Luma.App.exe`。
- 已安装 EXE 旧版：退出 Luma 后直接运行新版安装器；同一 Windows 用户的图库、收藏和设置会保留。
- `SHA256SUMS.txt` 校验下载，`build-info.json` 记录构建来源。Windows 11 x64，包内包含 .NET、WinUI 与 NVIDIA 运行库，不需要 FFmpeg、外部播放器或开发 SDK。

## 开始前与当前边界

HDR 显示需要 HDR 屏幕并开启 Windows HDR。RTX HDR / VSR 还需要兼容的 NVIDIA RTX 显卡与驱动；原生 HDR 照片不依赖 RTX。HEIC 及部分 HEVC 实况视频需要 Windows HEIF / HEVC 扩展。

请保留 iPhone 配套 MOV 与配对信息，Android 请使用完整动态原片；部分分享方式会移除视频。静态照片和视频的 HDR 分开判断：本版不播放 PQ / HLG / Dolby Vision 原生 HDR 动态视频，仍可查看可解码的静态照片；`.livp` 暂未支持。播放期间暂停 VSR。

首次实况播放或 AI 初始化仍可能等待；不承诺所有设备稳定 60 FPS，也未覆盖所有手机、编码和分享方式。GIF 动画、AVIF HDR、RAW 仍未支持。

当前 GitHub 包未做代码签名。微软商店 MSIX 使用单独手动构建流程，尚未上架；本次 GitHub Release 不等于商店发布。
