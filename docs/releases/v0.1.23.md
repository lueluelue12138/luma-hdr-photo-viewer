# Luma 0.1.23

**如果你有一块好 HDR 屏幕，别只用它看电影。也用它，重新看看自己的照片。**

这是 Luma 的首个公开 Release。免费、开源的 Windows 原生照片查看器，支持原生 HDR 照片，也能通过 NVIDIA RTX Video HDR 为普通照片增强光影。

## 下载

- **日常使用：**下载 `Luma-0.1.23-windows-x64-rtx-setup.exe` 安装，约 **58.28 MiB**。已安装旧版时，退出 Luma 后直接运行新版安装器即可升级；同一 Windows 用户的图库、收藏和设置会保留。
- **便携使用：**下载 `Luma-0.1.23-windows-x64-rtx-portable.zip`，约 **81.72 MiB**，完整解压后运行 `Luma.App.exe`。
- `SHA256SUMS.txt` 用于校验下载；`build-info.json` 记录源码和完整 RTX 构建信息。

支持 **Windows 11 x64**。包内已包含 .NET、WinUI 和 NVIDIA 运行库，无需安装开发 SDK。HEIC 另需 Windows 的 **HEIF 图像扩展与 HEVC 视频扩展**。

当前安装包与程序未做代码签名，Windows 可能显示安全提示。请仅从本项目 Release 下载并核对文件；微软商店版仍在准备。

## 可以体验什么

- **让普通照片用上好屏幕。** NVIDIA RTX Video HDR 增强 SDR 照片的光影；VSR 超分独立开关，默认关闭。
- **直接欣赏原生 HDR。** 支持 Ultra HDR / ISO / Apple 增益图 JPEG、兼容的 Apple / ISO 增益图及 PQ HEIC、线性 scRGB JXR / WDP / HDP 截图。
- **顺手看自己的回忆。** 文件夹相册、搜索、收藏、最近打开、缩放拖拽和全屏；照片保留原位置。
- **原生界面与拍摄详情。** 深浅主题、悬浮毛玻璃工具栏、顶部信息入口与 EXIF；设置里可查看系统报告的 HDR 峰值并打开 Windows HDR 校准。
- **随时对比。** 按住空格查看原图或可用的 SDR 底图；部分原生 HDR 文件本身不含独立 SDR 底图。

## 开始前

HDR 显示需要 HDR 屏幕并开启 Windows HDR。RTX HDR / VSR 还需要兼容的 NVIDIA RTX 显卡与驱动；原生 HDR 不依赖 RTX。建议先用微软 HDR 校准应用调整屏幕，具体见 [HDR 入门](https://github.com/lueluelue12138/luma-hdr-photo-viewer/blob/main/docs/HDR-SETUP.md)。

首个公开版本还会继续完善：大相册首次缩略图、未缓存的大图与 AI 首次初始化可能需要等待；AVIF HDR、RAW、HLG HEIC 的完整验证和动画播放暂未提供。AI 增强不等于恢复原本没有记录的信息，也不保证所有区域都更亮。完整格式范围见 [格式说明](https://github.com/lueluelue12138/luma-hdr-photo-viewer/blob/main/docs/HDR-FORMATS.md)。

欢迎在 [Issues](https://github.com/lueluelue12138/luma-hdr-photo-viewer/issues) 分享体验。Luma 是独立项目；NVIDIA 组件适用随包提供的独立许可，MIT 仅覆盖 Luma 原创部分。

Free, open-source native Windows photo viewer. Rediscover SDR photos with NVIDIA RTX Video HDR, or view supported native HDR images directly. Download the **setup.exe** installer or extract the complete **portable.zip**. Windows 11 x64; compatible RTX GPU/driver for RTX features, HDR display with Windows HDR enabled for HDR output. HEIC requires Windows HEIF/HEVC extensions. The current UI is primarily Simplified Chinese; this release is unsigned. See the README for format support and known limitations.
